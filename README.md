# tilt-for-the-win-website

Static marketing site for **Tilt for the Win**: https://tilt-for-the-win.zdravkov.dev

Plain HTML/CSS served by GitHub Pages from `main` (no build step). The game itself lives in
[ivan-zdravkov/tilt-for-the-win](https://github.com/ivan-zdravkov/tilt-for-the-win).

- `index.html`: landing page
- `privacy.html`: privacy policy (linked from both store listings, so **don't rename it**)
- `app-ads.txt`: AdMob authorized sellers (added once the AdMob account exists)
- `CNAME`: custom domain. DNS is a GoDaddy CNAME `tilt-for-the-win` → `ivan-zdravkov.github.io`.
